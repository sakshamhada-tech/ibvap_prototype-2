# Contributing

This is a proprietary repository. Contributions require authorization from the
repository owner and do not change the ownership or licensing of the project.

1. Work on a short-lived branch.
2. Never commit credentials, operational footage, generated logs, or personal
   data.
3. Run `make check` before submitting a change.
4. Add tests for analytics, security, or lifecycle behavior that changes.
5. Explain model/dependency changes, including provenance, checksum, license,
   and measured accuracy/performance impact.
6. Keep camera-specific values in environment configuration, not source code.

Security concerns should follow `SECURITY.md`, not a public issue.
